# 每类物料录一个视频即可

先看[团队拍摄示例](拍摄示例说明.md)。参考托盘内摆放和物料完整入镜的方式，正式录制请关闭时间、地点水印。

九类物料，每类约1–2分钟，再加2–3段混合场景。先拍一小段确认清晰度和视角，再批量采集。

1. 固定最终实物相机和安装视角；手机拍摄需注明，仅作为补充。
2. 轮换同类不同个体和颜色，改变画面位置、旋转与稳定摆放朝向。
3. 每次摆好后手退出，静止2–3秒，再调整。每段约15–20种不同摆放即可，不以视频长度充数。
4. 混合视频每次摆3–8个不同类别，包含分散、接触、轻度遮挡，再补一小段空台。
5. 保留无滤镜、无文字、无检测框的原始视频，不经过聊天软件压缩。不拍人脸、屏幕或个人信息。

命名示例：`20261116_team01_cube_01.mp4`；中文名称也可以。填写 templates/metadata.md，注明日期、相机、类别、视角和光照。

## 视频如何交付

视频通常过大，不放进普通 Git 仓库。通过负责人约定的网盘或本地文件交接原片；当前没有配置自动上传网盘或自动抽帧服务。私密网盘链接和访问码私下交给负责人，不提交到公开仓库。

负责人收到后进行抽帧、相似帧去重、模糊与手部遮挡筛选。筛选后的 JPG/PNG 按 README 的 Fork 投稿流程上传，保留原视频文件名和帧时间，后续统一画框标注。单类视频名称不能代替检测框。

同一视频及同场景连续拍摄应归入同一数据划分。独立测试另外拍摄，不能将相邻帧分散到训练和测试中。
